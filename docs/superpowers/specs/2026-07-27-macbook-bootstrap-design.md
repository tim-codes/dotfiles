# Macbook Bootstrap & Setup Refresh — Design

Date: 2026-07-27

## Goal

On a brand-new macbook, after installing 1Password (app + SSH agent + CLI
integration enabled), a single command sets up the whole dev environment:

```
curl -fsSL https://raw.githubusercontent.com/tim-codes/dotfiles/main/scripts/bootstrap | zsh
```

## Prerequisites (manual, before running bootstrap)

1. Install 1Password and sign in.
2. In 1Password Settings → Developer:
   - Enable **Use the SSH Agent**
   - Enable **Integrate with 1Password CLI**
   - Enable **Generate SSH config file with bookmarked hosts** (writes
     `~/.ssh/1Password/config` with the `IdentityAgent` setting)

## Architecture

Thin bootstrap + existing scripts. `scripts/bootstrap` only handles what must
happen *before* the repo exists locally, then hands off to the existing
`scripts/init` → `scripts/setup-macbook` chain. All heavy lifting stays in the
repo where it is versioned and re-runnable.

### New: `scripts/bootstrap` (zsh, idempotent)

1. Install Xcode Command Line Tools; wait-loop until `xcode-select -p`
   succeeds (git is needed for the clone).
2. Ensure `~/.ssh/config` uses the 1Password agent:
   - If `~/.ssh/1Password/config` exists (generated by 1Password), ensure
     `Include ~/.ssh/1Password/config` is the first line of `~/.ssh/config`.
   - Otherwise append a `Host *` block with the 1Password `IdentityAgent`
     socket path.
3. Pre-seed `github.com` into `~/.ssh/known_hosts` via `ssh-keyscan` so the
   clone never prompts.
4. Clone `git@github.com:tim-codes/dotfiles.git` → `~/dev/dotfiles` with
   `--recurse-submodules`; if already cloned, `pull --ff-only` and update
   submodules instead.
5. Exec `~/dev/dotfiles/scripts/init`.

### Changed: `scripts/setup-macbook`

- Install Alacritty via `brew install --cask alacritty` (guarded on
  `/Applications/Alacritty.app`); the custom `scripts/install-alacritty-mac`
  dmg-download script is deleted.
- New tmux plugins step: clone TPM to `~/.tmux/plugins/tpm` if missing, then
  run its non-interactive `bin/install_plugins`.

### Changed: `src/.tmux.conf`

- `default-shell` no longer points at the stale nix path
  (`~/.nix-profile/bin/fish`); it is set via `if-shell` to the homebrew fish
  path on mac with a `/usr/bin/fish` fallback for linux.
- Catppuccin theme is managed by TPM (`set -g @plugin 'catppuccin/tmux'`)
  instead of a manual `run` line pointing at a never-installed path.

### Unchanged

- `src/.config/alacritty/alacritty.toml` keeps launching fish directly; tmux
  is started manually when wanted.
- Clone method is SSH via the 1Password agent (prereq guarantees it works).

### Docs

- `README.md` macbook setup section rewritten around the one-liner: prereqs,
  the curl command, what it does, and the remaining manual steps (GPG signing
  key config, manual app installs).
- `CLAUDE.md` Key Commands updated to mention `scripts/bootstrap`.

## Error handling

- Every step of bootstrap is idempotent and safe to re-run after a failure.
- Bootstrap fails fast (`set -euo pipefail`) except where a step is
  legitimately optional/best-effort.

## Testing

- `zsh -n` / `bash -n` syntax checks on all touched scripts.
- tmux config smoke-tested by starting a throwaway server against the new
  conf on the current machine.
- Full end-to-end run happens on the new macbook (the real test).
